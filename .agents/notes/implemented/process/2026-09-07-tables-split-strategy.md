# Agent Note: 第三種抽取策略 tables-split

Status: implemented

## Problem

社會、自然科學、英語文的指標表都是「依學習階段並排」的多欄表，
而且**同一個儲存格裡會塞進好幾筆指標**：

```
Aa-Ⅱ-1 個人在家庭、學校與社
會中有各種不同的角
色，個人發展也會受其
影響。
Aa-Ⅱ-2 不同群體（可包括年齡、
性別、族群、階層、職業、
區域或身心特質等）應
受到理解、尊重與保護，
```

既有的兩種策略都失敗：`lines` 會被欄位交錯打散（英語文只抓到 28%），
`tables` 把整格當一筆，得到多筆合併的亂碼。

## Decision

新增 `tables-split`：先取儲存格，再依代碼出現位置切段，
每段代碼後到下一個代碼前的文字就是該筆的敘述。

三個領域都達到 **100% 完整**（社會 500/500、自然科學 401/401、英語文 401/401）。

## 順帶處理的跨頁截斷

英語文的 `D-Ⅲ-3` 在第 22 頁只印到「依綜合」，續文「資訊作簡易猜測。」
在第 23 頁的續表首欄。抽取器兩段都看得到，但無法自動判斷屬於同一筆。

profile 以 `continuations` 明確宣告，並註明來源頁碼供查核。
**這是把兩個已抽取的片段接起來，不是憑空補字**——區別很重要。

## Consequences

三種策略並存，profile 決定用哪一種。新增領域的第一步是觀察 PDF 版面：
兩欄表用 `lines`，代碼儲存格垂直置中用 `tables`，
一格多筆用 `tables-split`。

完整性檢查會擋住選錯策略的情況——英語文第一次就是這樣被擋下的。
