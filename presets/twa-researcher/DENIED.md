# twa-researcher 刻意不給的能力

## `runtime-self-modify`

對執行中的 runtime 求值任意程式碼，等同 shell 存取且無審核點。
沒有任何研究任務需要這項能力。

## `persistent-terminal`

維持有狀態的終端機工作階段。

查核與產圖都是一次性呼叫，`shell` 已經足夠。關掉可縮小攻擊面。

## `plan-mode`

計畫模式與執行模式的切換。

查核工作流本身已經是分階段的（模式判斷 → 查核五步驟 → 格式彙整 → 報告），
再疊一層模式切換只會增加認知負擔。

## `lsp`

語言伺服器。本 preset 不做程式開發。

---

## 與教師模式的差別：`subagent` 在這裡是開的

`twa-teacher` 否決 `subagent`，理由是教案生成沒有可平行化的部分，
而 token 成本對教師不透明。

研究者模式不同：`tw-edu-citation-checker` 的批次查核天生可平行
（每筆引用彼此獨立），而且使用者是研究者，對成本與並行有預期。

這是刻意的差異，不是遺漏。
